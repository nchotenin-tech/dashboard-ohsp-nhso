# รายได้บริการทันตกรรม PP Fee Schedule สปสช.

Dashboard รายได้จากบริการทันตกรรม PP Fee Schedule ของ สปสช. ปีงบประมาณ 2569 ครบ 12 เขตสุขภาพ

- ตรวจและทำความสะอาดฟันหญิงมีครรภ์ (ANC กลุ่ม 05)
- เคลือบฟลูออไรด์ กลุ่มอายุ 25–59 ปี
- ตรวจชิ้นเนื้อมะเร็งช่องปาก (biopsy และพยาธิวิทยา)

กรองได้ตามเขต จังหวัด สังกัด รพ.สต. (สธ. / อบจ. / อปท.อื่น) และบริการ พร้อมส่งออกรายหน่วยบริการเป็น Excel

ดู Dashboard: https://nchotenin-tech.github.io/dashboard-ohsp-nhso/
